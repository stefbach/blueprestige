# Photos de la visite

Déposer ici les photos du bien, aux noms attendus par `src/tour/photos.js`.

La visite lit ce dossier directement : dès qu'un fichier porte le bon nom, il
remplace l'emplacement d'attente correspondant. Aucun autre fichier à toucher.
